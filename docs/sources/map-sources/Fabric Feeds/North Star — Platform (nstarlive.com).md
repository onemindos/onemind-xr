# North Star — Platform (nstarlive.com)

North Star is a unified 5-sector OSINT platform: Camera Globe (250k+ cameras + YOLOv8 AI), Username/Identity research, Crypto Tracing (22+ chains), NetScan (port/domain/Tor recon), and Watchtower (live global SA globe). Built on Shodan, OSM, NASA, MaxMind, GeoCLIP, YOLOv8. Subscription-based, no install. Founders-only Watchtower = maritime+aviation+hazards+infra+threats on one globe — direct parallel to what we're building on the fabric. Reference platform + potential API integration point.
