# OneMind Map Sources

Collected from the OneMind - 10-23-26 vault on this Mac. Original vault files were preserved.

- Fabric Feeds/: 160 main database records, plus the older LiveUAMap top-level copy retained separately by its original filename; database host and view files are also retained.
- Map Layers/: all 79 database records, plus database host and view files.
- Related Documents/: all other original documents retrieved during the feed/map investigation, including Geo DB, architecture, TAK sources and UI planning.
- Audit Reports/: full classified inventory, CSV, findings, provenance and supporting evidence from the investigation.
- The packaged audit zip is not copied here; its 22 files are identical to `Audit Reports/`.
- SOURCE-COPY-MANIFEST.json: original-to-desktop paths and SHA-256 checksums.
- AUDIT-COPY-MANIFEST.json: checksums of the transferred audit files.

These are catalog documents and audit evidence, not downloaded datasets or certified working integrations. Historical Live/Planned metadata is not a runtime health guarantee. The audit is dated October 28, 2026; files were copied from the current vault rather than reconstructed from shortened audit excerpts.

Copied into onemind-xr on 2026-10-29 for the build run. `.DS_Store` removed. Note: gitleaks flags `original_sha256` values in the CSV as generic API keys; they are file checksums, not secrets.
