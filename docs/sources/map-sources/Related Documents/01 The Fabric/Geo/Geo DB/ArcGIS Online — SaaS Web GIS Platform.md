# ArcGIS Online — SaaS Web GIS Platform

> ArcGIS Online is Esri's SaaS product — hosted web GIS platform. FedRAMP Moderate + ISO 27001 certified. Fortune 500 trusts it. Integrates with Snowflake, BigQuery, Databricks, Azure, Autodesk.
---
## What ArcGIS Online Is
- Hosted SaaS web GIS platform — zero infrastructure to deploy
- FedRAMP Moderate + ISO 27001 certified for US government use
- Works online + offline — maps sync when connection returns
- Thousands of resources: sample code, templates, pre-built apps, AI models
---
## Key Features
| Feature | What It Does |
| 2D/3D Maps | Interactive maps, immersive 3D scenes |
| Real-time Data | IoT/sensor feeds, live updates |
| Analysis Tools | Spatial joins, pattern detection, what-if scenarios, forecasting |
| AI-Enhanced | ML-enhanced analysis with Esri AI stack |
| Data Management | Collection, governance, enterprise scale |
| Sharing | Public/private sharing, embedded maps, StoryMaps |
| Developer Tools | ArcGIS Maps SDKs: JS, native mobile, .NET, Qt, Unreal, Unity |
| Field Apps | Collector, Survey123, QuickCapture — mobile data collection |
## OneMind vs ArcGIS Online
> OneMind does NOT compete head-on with ArcGIS Online.

ArcGIS Online = general enterprise GIS — mapping, analysis, dashboards, communications.
OneMind = dynamic tactical intelligence — real-time CoT, NATS bus, agent reasoning, physical AI coordination.

Win: same-day deployment, every platform, any machine, agent integration, open source, Linux-native.
| Capability | ArcGIS Online | OneMind OS |
| Real-time CoT | Polling dashboards | NATS pub/sub — live every |
| Voice/TAK | No native voice | LiveKit + om-presence + TAK |
| Agent AI | ArcGIS ML tools | Legacy mother — full orchestration |
| Mobile | ArcGIS Field Apps | Flutter — any platform |
| 3D Globe | Cesium via ArcGIS JS SDK | CesiumJS native — self-hosted |
| Deployment | SaaS only | K8s, edge, homelab, airgap |
| Cost | Per-user licensing | FOSS base |
