# Findings, 2026-10-29

Verified by reading public repositories (via `gh api`) and the web pages cited.
Claims marked *unverified* still need checking in M0.

## 1. The TAK kernel

TAK-Product-Center publishes three repos: `Server`, `VR` (GPL-3.0) and `atak-civ`
(GPL-3.0; federal-employee portions public domain).

- **Common Commo** (`atak-civ/commoncommo`) is the comms kernel. It is C++ with JNI,
  Objective-C and Win32 bindings. It handles mesh SA over UDP multicast (one CoT per
  datagram), TCP directed messages, TAK Server streaming, TAK Protocol negotiation
  (XML v0, protobuf v1), mission packages, certificate enrollment and QUIC.
- **TAK Kernel / Engine** (`atak-civ/takkernel`) is the map engine (about 500 C++
  files) plus `gov.tak.api` Java models. It builds for `android` (ATAK) or `java`
  (TAKX). It renders Cesium 3D Tiles through vendored cesium-native. Building it
  needs TAK artifact-repository credentials.
- **Wire spec:** `atak-civ/takproto` (README.txt, .proto files) and `takcot` (XSDs).
- CloudTAK and all of OneMind's own components (before the mesh gateway) used
  neither Commo nor the engine.

## 2. omos mesh gateway (branch `feat/tak-mesh-gateway` in omos)

`services/bridge/bridges/tak` v0.2.0 implements mesh SA, directed TCP and TAK
Protocol v1 negotiation in Go, written from the spec. It was cross-checked in
both directions against the `takproto` Python package. See omos
`docs/architecture/decisions/0003-tak-native-clients-and-mesh.md`. **Uncommitted
when this file was written**; check the branch state.

## 3. How intel dashboards handle many sources

| Pattern | worldmonitor (AGPL-3.0) | worldwideview (Elastic 2.0) | gods-eye-view (MIT) | osiris (MIT) |
|---|---|---|---|---|
| Collectors separate from the viewer | 228 `scripts/seed-*.mjs` plus a relay; "794 observed source hosts" | Data-engine runner loading seeders (interval, cron or init) | `server/providers/*` per source | Next.js API route per source |
| Latest-snapshot cache per layer | Redis key plus `seed-meta` (`fetchedAt`, staleness limit) | Redis `data:<plugin>:live`, WebSocket `/stream` and REST | Per-layer caches and health states | Server caches, stale kept on outage |
| Load layers on demand | Visible panels first, smart polling | Subscribe on visibility | Polling paused when hidden | On demand and viewport-aware |
| GPU batch rendering | deck.gl, supercluster | Cesium primitive collections, 500-entity chunks, horizon culling, glTF LOD | Cesium photoreal; 11,575 objects at 57.6 fps on an M5 (their PERFORMANCE.md) | MapLibre WebGL |

Scale is thousands to about 10,000 entities on screen. None has TAK, mesh, tasking
or actions. Licence consequence: do not copy worldmonitor or worldwideview code.

**Mapping to NATS:** stream per feed, KV for the latest snapshot, NATS WebSocket in
place of `/stream`, leaf nodes for the edge. What omos lacks is the snapshot layer
and the entity layer; and Redpanda Connect pipelines currently push every
aircraft, ship and transit item as CoT straight to `tak.cot.inject`.

## 4. VR-TAK

- Latest release `5.5-RELEASE-0` (2025-09-07); last push 2026-04-02; about 8.6 GB.
- README builds it on **Unreal Engine 5.3.2** from source, with an `EnginePatch`
  folder of **10,081 source files** copied over the engine. It is an engine fork.
- Commo ships only as Windows x64 binaries in `Game/Plugins/VH_COT`.
- Enabled plugins include OpenXR and WebBrowserWidget.
- Public `VH_Globe` source is geodesy (ENU, UTM, MGRS, quadkey, EGM96); no Cesium or
  3D Tiles code in the source tree.
- Plugins worth porting: `VH_COT`, `VTAK_Mensuration`, `VTAK_Orbit`,
  `VH_Replication`, `VH_SessionPlayback`, `VH_VR`.

## 5. Engine and platform facts

- **Cesium for Unreal** supports the three newest Unreal versions; v2.28.0 (July
  2026) added UE 5.8 and was the last to support 5.5. It cannot run on VR-TAK's
  5.3.2. Cesium for Unreal lists macOS, Windows, Linux, Android and iOS. A forum
  thread reports plugin issues on an M1 Pro with UE 5.6 (*check on the owner's Mac*).
- **Unreal on Apple Silicon:** native since UE 5.2.
- **Pixel Streaming on macOS:** *unverified for 5.8.* Community reports: Pixel
  Streaming 2 on UE 5.7 on an M4 connected but showed a flat colour; a setup-script
  architecture bug on Apple Silicon for 5.3.2–5.6. Spike S2.
- **Headset:** model DK94EC is the **Meta Quest Pro** (standalone, Android-based).
  Quest Link requires a Windows PC, so the Mac cannot drive it over Link. Options
  are a standalone build, streaming, or WebXR. Spike S3.

## 6. Comparable products

- **ARTAK (Eolian):** multi-domain planning and C2 on AR, VR, tablet, phone and PC;
  ATAK integration; Map Maker builds 3D maps from drone imagery; disconnected mode;
  server can run on your own PC or edge server. Commercial. Engine and web support
  not stated.
- **Argos Atlas:** live map of more than 200,000 cameras. Technology not visible from
  the page; no TAK.
